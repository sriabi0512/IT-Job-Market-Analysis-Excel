IT Job Market Analysis Dashboard

Project Overview

This project focuses on analyzing IT job market trends using Microsoft Excel. An interactive dashboard was developed to explore job openings, vacancies, salary trends, and remote work opportunities.

Key Performance Indicators (KPIs)

- Total Job Openings: 300
- Total Vacancies: 1,915
- Average Salary: 13.94 LPA
- Remote Jobs: 36%

Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

Dashboard Features

- 6 interactive charts
- 5 interactive slicers
- Timeline filter
- Dynamic dashboard analysis
